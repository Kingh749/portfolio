# Divya Shah - Premium Developer Portfolio

A premium, interactive personal portfolio website built with modern web technologies to showcase my projects, technical skills, and professional journey.

## 🚀 Features

- **Immersive Design:** Dark-themed, high-contrast aesthetic with ambient neon lighting and glassmorphism effects.
- **3D Parallax Hero:** Anti-gravity floating effects and smooth mouse-tracking parallax powered by Framer Motion.
- **Cinematic Overlays:** Film grain noise and dynamic split-lighting beam effects.
- **Scrolly-telling Experience:** Smooth scroll animations and transition effects guided by user interaction.
- **Responsive Layout:** Fully optimized for desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **Framework:** Vite + React (Optimized for maximum performance and fast bundling)
- **Styling:** Advanced Vanilla CSS (with CSS Variables, Glassmorphism, and Blend Modes)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **3D Elements:** [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Icons:** Custom SVG & Lucide React
- **Video:** HTML5 Video (WebP optimized for performance)
- **Hosting:** Custom Domain (`divyashah.tech`) setup with CNAME ready.

## 📂 Project Structure

```
├── public/              # Static assets (CNAME, front-video.webp, favicon)
├── src/
│   ├── App.jsx          # Main application logic, animations, and Hero structure
│   ├── index.css        # Global premium styles, glassmorphism, animations
│   ├── main.jsx         # React DOM rendering
├── index.html           # Main HTML entry point with SEO metadata
└── package.json         # Project dependencies and scripts
```

## 🚀 Quick Start & Deployment

1. **Local Development:** Run `npm run dev` to start the local Vite server.
2. **Build for Production:** Run `npm run build` to generate the highly optimized `dist/` folder.
3. **Deploying:** Upload the contents of the `dist/` folder to GitHub Pages, Vercel, or Netlify. The custom domain `divyashah.tech` is pre-configured via the `public/CNAME` file.
